Beyond Euclid's Elements, Dr. Joyce produced several smaller tutorials and demos using the same Geometry Applet. This edition republishes them, rendering their diagrams with geomlib.

  • Compass Geometry — a seven-part introduction to Euclidean constructions using compass and straightedge.
  • Spherical and inversive geometry tutorials:
    • Round triangles
    • Configuration of six circles and eight points
    • Desargues' Theorem
  • The Euler Line — a single-page interactive demo of the Euler line of a triangle.
